**ARQUITECTURA DEL COMPUTADOR**

Este repositorio contiene el desarrollo y la documentación del proyecto académico correspondiente al curso de Arquitectura del Computador, de la carrera de Ingeniería en Informática y Sistemas de la Universidad Rafael Landívar.
El proyecto tiene como finalidad aplicar los conocimientos teóricos y prácticos relacionados con la arquitectura, organización y funcionamiento de los sistemas computacionales, mediante el diseño, implementación y evaluación de una solución tecnológica.
